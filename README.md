# 📱 تطبيق "مصاريفي" (Masarifi) - المنظومة المالية الذكية للعائلة والأفراد

تطبيق ويب تقدمي (PWA) فائق التطور مصمم خصيصاً لإدارة الميزانية الشخصية والعائلية، تتبع النفقات والمداخيل، جدولة المصاريف المتكررة، تنمية الادخار، واستشارات مالية فورية مدعومة بالذكاء الاصطناعي (Gemini AI)، مع دعم كامل للبيئة التونسية والعربية والمزامنة السحابية الفورية.

---

## 🌟 أبرز المميزات والقدرات الشاملة

### 1. 📊 إدارة الميزانية والسيولة اليومية
- **الميزانية الشهرية المرنة**: تحديد سقف إنفاق إجمالي وتوزيع ميزانيات مخصصة لكل فئة مع تتبع النسب ومؤشرات الخطر.
- **حد الصرف الآمن اليومي (Daily Safe Spend)**: خوارزمية ذكية تحسب المبلغ المتاح صرفه يومياً بناءً على الأيام المتبقية في الشهر والالتزامات الثابتة.
- **تفريرة العيلة وميزانية الرضيع (Baby & Family Budget)**: نظام تتبع مخصص لنفقات الرضيع (حفاظات، حليب، طبيب، أدوية) مع مقارنات دورية وتحديات خفض الهدر.

### 2. ⚡ تسجيل المعاملات السريع والمتعدد
- **إضافة فائقة السرعة**: لوحة مفاتيح رقمية وحاسبة مدمجة مع دعم العمليات الحسابية المباشرة.
- **إرفاق الصور والمسح الذكي**: قراءة الإيصالات والفواتير وتصنيفها آلياً عبر الذكاء الاصطناعي (OCR & Vision AI).
- **إدارة المعاملات التفاعلية**: سحب لليمين/اليسار لتعديل أو حذف المعاملة (Swipe Actions)، وفلاتر متقدمة حسب الفئة، الحساب، والنوع.

### 3. 🎯 الادخار، الحصالة النقدية، والأهداف المالية
- **أهداف ادخارية متقدمة (Savings Goals)**: إنشاء أهداف محددة زمنياً (صندوق طوارئ، سيارة، عطلة) مع إيداع أقساط سريعة وتوزيع ذكي للفائض.
- **الحصالة النقدية المادية (Cash Piggy Bank)**: تتبع الفكة الملموسة والنقود المحفوظة في المنزل مع أزرار إيداع وتفريغ فوري.
- **تقريب الفكة التلقائي (Auto Round-Up)**: تجميع كسور المشتريات تلقائياً لأقرب دينار أو مضاعفاته وتحويلها للحصالة.
- **محاكي التوفير الذكي (Smart Simulator)**: تجربة تفاعلية لمحاكاة الوفر المالي عند ترشيد مصاريف معينة (المقاهي، قفة السوق، الترفيه).

### 4. 🔄 المصاريف المتكررة والاشتراكات (Recurring Expenses)
- **إدارة الفواتير والاشتراكات الدورية**: متابعة فواتير الماء والكهرباء (STEG / SONEDE)، الإيجار، الإنترنت، وأقساط القروض.
- **تنبيهات الاستحقاق والإسقاط الآلي**: تذكيرات بمواعيد الدفع مع زر تسجيل فوري يسقط الفاتورة من الحساب المحدد.

### 5. 📈 التحليلات والرسوم البيانية المتقدمة (Analytics & Charts)
- **مخططات التدفق اليومية والتراكمية**: مقارنة حركة المقابيل والمصاريف، وتتبع منحنى السيولة النقدية الصافية يوماً بيوم.
- **توزيع الفئات ومصادر الدخل**: مخططات دائرية (Donut Charts) توضح أكبر مصارف الأموال ومصادر المداخيل.
- **تحليل الأسابيع والمقارنة الشهرية**: قياس الأداء الأسبوعي مقارنة بالمعدل التراكمي.

### 6. 🤖 المستشار المالي بالذكاء الاصطناعي (Gemini AI Advisor)
- **مساعد مالي تفاعلي**: محادثة نصية لطلب مشورات واستراتيجيات لتقليص النفقات والاستثمار.
- **تحليل السلوك المالي**: تشخيص العادات الاستهلاكية، اكتشاف فخاخ الإنفاق، وتقديم نصائح مخصصة فورية.

### 7. 🔒 الأمان وتجربة الاستخدام المتقدمة
- **قفل الشاشة برمز سري (PIN Lock & Biometric Feel)**: حماية الخصوصية وقفل التطبيق عند الخمول.
- **دعم كامل للوضع الداكن (Dark Mode)** واللغة العربية بالكامل بتصميم عصري وأنيق.
- **تطبيق هاتف تقدمي (PWA)**: إمكانية التثبيت المباشر على الشاشة الرئيسية للهاتف والعمل بمرونة في حالة عدم توفر الإنترنت (Offline Support).

## 🏗️ البنية التقنية (Tech Stack)

| المجال | التقنيات المستخدمة |
| :--- | :--- |
| **الواجهة الأمامية** | React 18+, TypeScript, Vite |
| **التنسيق والتصميم** | Tailwind CSS, Lucide React (Icons) |
| **الحركات والتفاعل** | Framer Motion (`motion/react`) |
| **البيانات والرسوم** | Recharts, Date-fns |
| **الخلفية وقاعدة البيانات** | Firebase Firestore, Firebase Authentication |
| **الذكاء الاصطناعي** | Google Gemini API SDK (`@google/genai`) |
| **إدارة الحالة والتخزين** | React Context API + LocalStorage + Firestore Sync |

## 🚀 دليل التثبيت والتشغيل المحلي

### المتطلبات الأساسية
- تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث).
- مدير الحزم `npm` أو `yarn`.

### خطوات التشغيل
1. **استنساخ المشروع وتثبيت الحزم**:
   ```bash
   npm install
   ```

2. **تهيئة المتغيرات البيئية**:
   قم بإنشاء ملف `.env` واضبط المتغيرات المطلوبة:
   ```env
   GEMINI_API_KEY=your_gemini_api_key_here
   ```

3. **تشغيل الخادم المحلي للتطوير**:
   ```bash
   npm run dev
   ```
   *سيعمل التطبيق افتراضياً على المنفذ `http://localhost:3000`*.

4. **بناء نسخة الإنتاج**:
   ```bash
   npm run build
   ```

## 🔒 الأمان وحماية البيانات

- **التشفير والمصادقة**: بيانات المستخدمين مؤمنة عبر Firebase Authentication و Firestore Security Rules.
- **الخصوصية التامة**: لا يتم مشاركة أي بيانات مالية خارج نطاق الاستخدام الشخصي، والذكاء الاصطناعي يعمل ضمن نطاق الأمان المعتمد.
- **حماية إضافية**: ميزة القفل التلقائي برمز PIN لحماية التطبيق عند تركه مفتوحاً على الهاتف.
