# تطبيق "مصاريفي" (Masarifi) - المستشار المالي الذكي

تطبيق متكامل لإدارة الميزانية الشخصية، تتبع المصاريف، وتحليل البيانات المالية باستخدام الذكاء الاصطناعي.

## 🚀 التقنيات المستخدمة

- **React 18+ & TypeScript**: لبناء واجهة مستخدم قوية ومنظمة.
- **Vite**: كأداة بناء سريعة وفعالة.
- **Tailwind CSS**: للتصميم العصري والمتجاوب.
- **Framer Motion (motion/react)**: لإضافة حركات وتفاعلات سلسة (Animations).
- **Firebase (Firestore & Auth)**: لتخزين البيانات والمزامنة السحابية وتأمين حسابات المستخدمين.
- **Google Gemini AI SDK**: لتشغيل المساعد المالي الذكي وتحليل البيانات.
- **Recharts**: لتمثيل البيانات المالية والرسوم البيانية.
- **Lucide React**: لمجموعة الأيقونات العصرية.
- **Date-fns**: لمعالجة التواريخ والوقت.
- **React Hot Toast**: لعرض التنبيهات والإشعارات.

## ✨ المميزات الرئيسية

- **إدارة الحسابات المتعددة**: تتبع أرصدة الكاش، البنك، والبطاقات الائتمانية في مكان واحد.
- **تتبع المصاريف والدخل**: تسجيل العمليات المالية بسهولة مع تصنيفات فرعية.
- **الميزانية الذكية**: تحديد ميزانية شهرية ومراقبة الاستهلاك في الوقت الفعلي.
- **المستشار الذكي (AI)**: مساعد مالي مدعوم بـ Gemini لتحليل الإنفاق، تقديم نصائح، وقراءة الفواتير من الصور.
- **أهداف الادخار**: تحديد أهداف مالية ومتابعة التقدم نحو تحقيقها.
- **التحليلات والتقارير**: رسوم بيانية مفصلة توضح أين تذهب أموالك.
- **وضع عدم الاتصال (Offline Mode)**: إمكانية استخدام التطبيق حتى بدون إنترنت مع مزامنة تلقائية لاحقاً.

## 📂 هيكل المشروع والمكونات

### الصفحات (Pages)
- `Dashboard`: لوحة التحكم الرئيسية مع ملخص سريع.
- `Transactions`: سجل كامل لجميع العمليات المالية مع فلاتر متقدمة.
- `Budget`: إدارة الميزانية الشهرية وتوزيعها على الفئات.
- `Analytics`: تحليلات عميقة ورسوم بيانية للإنفاق والدخل.
- `Savings`: أدوات متقدمة للادخار وتتبع الفوائض المالية.
- `Goals`: إدارة أهداف الادخار طويلة وقصيرة المدى.
- `Accounts`: إدارة الحسابات المالية والتحويلات بينها.
- `Assistant`: واجهة الدردشة مع المساعد الذكي.
- `Settings`: إعدادات التطبيق، العملة، والوضع الليلي.

### المكونات (Components)
- `AIAdvisor`: يعرض نصائح وتوقعات مالية ذكية في لوحة التحكم.
- `AddExpenseModal`: نافذة إضافة العمليات المالية (مصروف، دخل، تحويل).
- `TransactionItem`: مكون عرض العملية المالية مع دعم الحركات (Animations) والسحب للحذف.
- `NumericKeypad`: لوحة مفاتيح مخصصة لإدخال المبالغ بسرعة.
- `Header` & `BottomNav`: مكونات التنقل الرئيسية.
- `LoadingScreen`: شاشة الانتظار التفاعلية.

## 🛠️ كيفية التشغيل

1. قم بتثبيت التبعيات: `npm install`
2. ابدأ خادم التطوير: `npm run dev`
3. قم ببناء نسخة الإنتاج: `npm run build`

## 🔐 الأمان والخصوصية

- يتم تأمين بياناتك عبر Firebase Authentication.
- يتم تخزين مفاتيح API الخاصة بالذكاء الاصطناعي بشكل آمن في المتصفح أو البيئة البرمجية.
- يدعم التطبيق قواعد أمان Firestore (Security Rules) لضمان عدم وصول أي مستخدم لبيانات غيره.
